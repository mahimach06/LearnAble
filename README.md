
# LearnAble

LearnAble is a web application developed for my SOEN 287 Web Programming course at Concordia University.

## About the Project

LearnAble is designed to help students learn at their own pace through simple explanations, interactive lessons, and personalized learning preferences.

The goal is to make learning more accessible and easier to follow.

## Features

- User registration and login
- Personalized learning dashboard
- Interactive math lessons
- Addition, subtraction, multiplication, and division exercises
- Larger text accessibility option
- Step-by-step explanations
- Learning progress tracking

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js

## How to Run

1. Download or clone the repository.
2. Open the LearnAble project folder.
3. Install dependencies using "npm install".
4. Start the server using "npm start".
5. Open " http://localhost:3000 " in your browser.

## Project Status

The project currently includes a working front end, authentication functionality, interactive math lessons, and a learning dashboard.

Additional improvements will be made as development continues.
